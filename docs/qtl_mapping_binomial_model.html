Overview

We map genetic effects on pseudouridylation (%pU) with the count-based model as a starting point: model the raw converted-read counts as binomial, test the genotype effect on the log-odds of the modification rate, and read significance from the GLM p-value — using permutation to check that the p-values are calibrated, then standard site-level multiple-testing correction for QTL mapping.

Sites tested: the 5-fold union (called in ≥ 1 fold) set, 12,416 sites (see the 5-fold site-calling page). Samples: the 50 genotyped cell lines.

The model

For a given pU site, let individual \(i\) have \(y_i\) converted reads out of \(n_i\) total reads (\(n_i = C_i + T_i\), the read depth at that site):

\[ y_i \mid p_i \;\sim\; \text{Binomial}(n_i,\, p_i) \] \[ \text{logit}(p_i) \;=\; \beta_0 \;+\; \beta_g\, G_i \;+\; z_i^\top \gamma \]

  • \(p_i\) — the site’s true modification rate in individual \(i\).
  • \(n_i\) — read depth; enters as the binomial trial count, so low-depth observations automatically carry less weight.
  • \(G_i \in \{0,1,2\}\) — genotype of the test SNP (a cis variant near the site).
  • \(\beta_g\) — the genetic effect we test.
  • \(z_i\) — covariates (e.g. genotype PCs to correct population structure); optional in this first pass.

This is a standard binomial GLM (logit link). It is the simplest member of the count-model family — no overdispersion parameter, no random effects.

QTL mapping: per-SNP p-value from the GLM

For each (site, cis-SNP) pair, fit the full and null models and take the p-value for the genotype effect \(\beta_g\) from a likelihood-ratio test (LRT):

\[ \Lambda \;=\; 2\big(\log\text{Lik}_{\text{full}} - \log\text{Lik}_{\text{null}}\big) \;\overset{H_0}{\sim}\; \chi^2_1, \qquad H_0:\ \beta_g = 0 \]

full <- glm(cbind(C, N - C) ~ G + Z, family = binomial)   # Z = M-value PCs
null <- glm(cbind(C, N - C) ~     Z, family = binomial)
p_snp <- anova(null, full, test = "LRT")[["Pr(>Chi)"]][2] # p-value for beta_g

Why the LRT and not a faster score test. A Rao score test (fit the null once per site, test every cis-SNP via a fast vectorized computation) was tried first, since it’s asymptotically equivalent to the LRT and far cheaper to permute. It was found unreliable at exactly the sites that matter most:

  • It can be spuriously overconfident. When a cis-SNP’s true full-model fit sits near a separation boundary, the score test — which never actually fits that full model, only extrapolates from the null model’s local curvature — can report absurd significance (e.g. one real site: score \(p=2.5\times10^{-222}\) vs. the LRT’s \(p=1.8\times10^{-11}\) for the same SNP). This is the Hauck–Donner effect, a known structural property of score/Wald tests near boundaries, not a fixable numerical bug.
  • It can also correctly refuse to answer exactly where the LRT finds its strongest signals — its own numerical guards return NA for SNPs with a genuinely clean genotype-outcome split (e.g. one real site: 42/50 individuals at one dosage showing ~0% modification), which the LRT can still compute a valid statistic for.

Confirmed on real data (5kb, 3 PCs, 11,063 matched sites): same lead SNP only 57.4% of the time, rank correlation 0.875 (nominal p) / 0.770 (permutation-calibrated p) between the two tests. The LRT is the trusted method for anything reported as a discovery — the score test is not reliable at face value for individual sites, especially the most extreme-looking ones, which are exactly the sites most likely to be reported as top hits.

The practical cost of this choice: an LRT needs a full-model refit per cis-SNP (not one null fit per site), so genome-wide permutation is only feasible split by chromosome (and, for a few unusually dense loci, further by chunk) across many parallel jobs — see the results page for the actual grid runtime.

Significance

We follow the standard human cis-QTL approach — GLM p-value, a permutation calibration check, then two-level multiple-testing correction.

1. Permutation as a calibration check

The plain binomial GLM assumes no overdispersion. If %pU is overdispersed across cell lines, the analytic LRT p-values are anti-conservative. So we use permutation to audit the p-values (not to set a threshold):

  1. Permute the phenotype and covariates together across the 50 cell lines (the M-value PC covariates are derived from phenotype, so they must travel with whichever individual’s phenotype they were computed from; genotype stays fixed at its true per-individual values — this is what severs the genotype-phenotype link without introducing a phenotype/covariate mismatch); refit; record the \(\beta_g\) p-value. Repeat 5 times.
  2. Under the null these p-values should be Uniform\((0,1)\) — check the QQ-plot and the genomic-inflation factor \(\lambda = \text{median}(\chi^2_{\text{obs}}) / 0.455\); we want \(\lambda \approx 1\).

Result (5kb, 3 PCs): permuted-null \(\lambda\approx\)3.28 (range 2.93-3.44 across 5 seeds), real data \(\lambda=\)5.55. This is a real improvement over the score test’s numbers at the same config (real \(\lambda=7.54\), permuted-null \(\approx3.8\)), but the permuted-null is still well above the ideal 1 — since this is the nominal LRT p-value under permutation (not the numerical artifacts the score test was prone to), the residual inflation reflects genuine overdispersion the plain binomial model doesn’t account for (~22% of sites are significantly overdispersed by a separate test — see the beta-binomial page), not a fixable numerical issue in the test itself. See the results page for the table and QQ-plot.

# null distribution of the LRT p-value under permuted phenotype+covariates
perm_p <- replicate(n_perm, {
  o  <- sample(length(y))
  yp <- y[o]; np <- n[o]; Zp <- Z[o, , drop = FALSE]   # G is NOT reindexed
  f  <- suppressWarnings(glm(cbind(yp, np - yp) ~ G + Zp, family = binomial))
  n0 <- suppressWarnings(glm(cbind(yp, np - yp) ~     Zp, family = binomial))
  anova(n0, f, test = "LRT")[["Pr(>Chi)"]][2]
})
# QQ-plot perm_p vs Uniform(0,1);  lambda = median(qchisq(1 - perm_p, 1)) / qchisq(0.5, 1)

2. Within-site correction across cis-SNPs (gene level)

Each pU site is tested against many cis-SNPs in its window, which are correlated by LD. We collapse them to one p-value per site with the FastQTL / tensorQTL permutation beta-approximation:

  1. Compute the nominal p for every cis-SNP of the site; keep the minimum \(p_{\min}\).
  2. Permute the phenotype across cell lines \(B\) times; for each permutation recompute the min p over the same cis-SNPs → a null distribution of min-p.
  3. Fit a Beta\((a, b)\) to those null min-p values; the site’s adjusted p-value is the Beta CDF evaluated at the observed \(p_{\min}\).

This is the same gene-level correction used in the earlier tensorQTL run, now wrapped around the binomial GLM.

3. Across-site correction (genome-wide)

Apply Benjamini–Hochberg FDR (or Storey q-values) to the per-site adjusted p-values. Sites passing e.g. FDR < 0.05 are pU-QTL; report the lead SNP per significant site.

Data

  • Sites: 5-fold union, ≥ 1 fold — 12,416 pU sites. (A stricter ≥ k-fold set could be substituted; see the 5-fold page https://xsun1229.github.io/pumseq/mRNA_5fold_union_site_calling.html.)
  • Phenotype: per site, per cell line — converted reads \(C\) (= \(y\)) out of total depth \(N\) (= \(C+T\)), from the pooled joint counts.
  • Genotypes: cis SNPs within a window of each site (e.g. ±5kb, 20kb, 50kb, 100kb), from the imputed genotypes of the 50 cell lines.
  • Covariates \(z\): phenotype PCs computed from M-values (see below).

Covariates: M-value phenotype PCs

We follow the approach used in the IMAGE paper (https://pubmed.ncbi.nlm.nih.gov/31651351/), which adjusts for the top methylation principal components computed from M-values.

How they are computed. For each site \(s\) and cell line \(i\), convert the counts to an M-value — the log-odds of the modification rate, with a pseudocount so that \(y = 0\) or \(y = n\) stay finite:

https://link.springer.com/article/10.1186/1471-2105-11-587

\[ M_{si} \;=\; \log_2 \frac{y_{si} + \pi_s}{\,n_{si} - y_{si} + (1 - \pi_s)\,}, \qquad \pi_s \;=\; \frac{\sum_i y_{si}}{\sum_i n_{si}} \]

Choice of pseudocount. A pseudocount acts as a prior, and its ratio sets the value each observation is shrunk toward: an empty cell (\(y = n = 0\)) gives an implied modification rate of \(\alpha / (\alpha + \beta)\). A fixed \(1{:}1\) pseudocount therefore shrinks every site toward \(p = 50\%\) — far too high for pseudouridylation, where most sites have a low modification rate, and the bias is worst exactly at low depth with few modified reads (where a pseudocount of 1 is large relative to the actual counts). Instead we use a site-specific pseudocount \((\pi_s,\ 1 - \pi_s)\), where \(\pi_s\) is the site’s overall modification rate pooled over all reads across all samples. This shrinks each sample toward the site’s own mean rate \(\pi_s\) rather than \(50\%\)

Then:

  1. Standardize each site across cell lines (centre and scale each row), so that no individual site dominates the components.
  2. PCA across individuals on the standardized M-value matrix.
  3. Include the top \(k\) PC scores (one value per cell line) as the covariates \(z_i\) in the binomial GLM.
# C, N : sites x cell lines (converted, total)
pi <- rowSums(C) / rowSums(N)                  # per-site rate, pooled over samples
M  <- log2((C + pi) / (N - C + (1 - pi)))      # site-specific pseudocount (pi, 1-pi)
Ms <- t(scale(t(M)))                            # standardize each site
Ms[!is.finite(Ms)] <- 0
pc <- prcomp(t(Ms), center = TRUE, scale. = FALSE)
z  <- pc$x[, 1:k, drop = FALSE]                 # cell lines x k covariates

How many PCs. Not fixed in advance — we will sweep \(k \in \{3, 5, 7, 10, 15, 20\}\) and choose based on the results, as was done for the earlier tensorQTL PC sweep.
