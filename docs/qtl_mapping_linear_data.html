1. Sites

The sites come from union site calling. Each of the 51 sequenced cell lines is called on its own (chi-squared test against pooled input, FDR < 0.01, rate difference > 0.05, depth >= 20), and a site enters the list if any cell line calls it. Details are on the union site-calling QC page.

Two filters are then applied for QTL mapping:

The last count, 5,582, is the number of sites in the phenotype matrix.

2. Phenotype

For each site and cell line:

  1. Treated %pU: converted reads C / (C + T) in the treated library, with treated replicates pooled.
  2. Input %pU: the same ratio in the cell line’s pooled input (untreated) library. This is the background conversion rate.
  3. Treated minus input. Negative differences are set to 0, since treatment should only add signal on top of background. This changes 13.3% of the measured values at these sites; with the 24.1% that are exactly 0 already, 37.4% of values end up at 0.
  4. Missing values (no coverage in a cell line, 1.0% of entries) are filled with the site’s median across cell lines.
  5. Quantile normalisation across cell lines, so every cell line has the same distribution of values.

The result is a 5,582 x 50 matrix (sites x cell lines), written as a BED file for tensorQTL.

3. Covariates

Principal components of the normalised phenotype matrix (cell lines as observations, sites as features, centred). Covariate files with 3, 5, 7, 10, 15, 20, 25 and 30 PCs are produced; the scans sweep 3 to 30.

4. Genotypes

Source. Imputed genotypes for 60 Yoruba (YRI) lymphoblastoid cell lines, downloaded from Zenodo record 3870952, on hg19. They were lifted to hg38 with GATK LiftoverVcf (4.5.0, UCSC hg19ToHg38 chain); variants that could not be lifted were dropped.

Processing (2.qtl_mapping_linear/1.run_merge_genotype_vcf.sbatch, then 4.convert_genotype_plink2.sbatch):

  • chromosomes 1-22 merged into one VCF (chrX excluded);
  • subset to the 50 sequenced cell lines that have genotypes, and renamed from NA##### to CL##### to match the phenotype;
  • converted to PLINK2 format, keeping chr1-22 only, with every variant ID reset to chrom:pos:ref:alt (the VCF has missing and duplicated rsIDs) and half-calls set to missing.

What the linear model uses: all 9,794,847 variants in that PLINK2 file. No minor-allele-frequency filter is set, which is tensorQTL’s default. (The binomial and beta-binomial models use a filtered SNP set; see their data pages.)
