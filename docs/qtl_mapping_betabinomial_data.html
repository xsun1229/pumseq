1. Sites

The starting point is the same 5-fold union site set as the binomial model (see its data page and the 5-fold site-calling page). Two filters are applied by 13.filtered_phenotype.R:

Why the U/C filter. pU is read out as a T-to-C change. If a cell line carries a C (or, on the minus strand, a G) at the pU base in its genome, its reads show “conversion” without any modification, and the site’s %pU tracks genotype. Such sites look like strong pU-QTLs but are genotype read-outs. A site is removed if a C/T variant (plus strand) or A/G variant (minus strand) was called on the pU base.

What the untreated controls add. Untreated RNA has no chemical conversion, so a C there is inherited. The exclusion record cross-tabulates the two signals:

So 1,057 sites with inherited C in the untreated controls but no called variant are still in this phenotype. These are variants missing from the genotype calls. A stricter version that also removes them exists (fold5_union_noUC, built with --criterion both; calibrated on the U/C-aliasing calibration page) but is not the one used here.

2. Phenotype

The raw counts, as for the binomial model: for each site and cell line, C converted reads and N = C + T total reads at the pU base in the treated library, with treated replicates summed. No normalisation or imputation. The matrix is 10,738 sites x 50 cell lines, with 92.7% of entries covered by at least one read (median depth 9 reads where covered).

3. Covariates

M-value PCs, computed as for the binomial model (\(M = \log_2[(C + \pi_s)/(T + 1 - \pi_s)]\) per site and cell line, standardised per site, PCA across cell lines), but recomputed on the filtered sites. The original PCs were derived from all sites, including the genotype read-outs, so they could partly encode genetic structure. The recomputed PCs are close to the originals:

4. Genotypes

The same SNP set as the binomial model: imputed YRI genotypes from Zenodo record 3870952, lifted to hg38, restricted to the 50 sequenced cell lines, then filtered to 8,538,509 biallelic SNPs with minor-allele frequency >= 0.05 (dosages in genotype_common.traw). The full processing is on the linear model’s data page and the filter on the binomial model’s data page.

At each site the SNPs within the cis window are taken, missing dosages are filled with the SNP’s mean, and the MAF >= 0.05 filter is applied again.

5. Fitting choices that affect the data used

  • Fitter: multi-start maximum likelihood (starts at phi = 0.01, 0.1, 0.5; the best fit is kept). This is the default for all analyses; see the optimiser page.
  • Cell lines per test: every cell line with at least one read at the site is used.
  • Tests that cannot be fitted (separation, or a mean of exactly 0 or 1) are dropped; about 11% of cis tests at +/-5 kb.
